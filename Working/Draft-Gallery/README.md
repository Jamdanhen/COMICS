# Around Here Draft Gallery

Status: active working index

Open the gallery here:

`C:\COMICS\Working\Draft-Gallery\index.html`

The gallery separates:

- almost-finished comics and visual pages
- standalone symbol drafts
- active character drafts
- written-only candidates
- superseded and inactive generated versions

The gallery is read-only. It references images in their existing project
locations and does not copy, rename, move, approve, or promote artwork.

Approved comic pages and approved vocabulary references are intentionally
excluded from the pending sections.

To rebuild the gallery after draft status changes, run:

```powershell
powershell.exe -ExecutionPolicy Bypass -File C:\COMICS\Scripts\Build-DraftGallery.ps1
```
